# 世界还很大 · YanZ

YanZ 的个人旅行与生活网站。根据本人说明和帖子正文中的旅行日期，按时间排列十段旅程。故事与漫画继续留白；越南日期待补。日本包含东京、名古屋、大阪、京都，并保留两段日期区间。另有香港与两段泰国行程。

## 本地预览

需要 Node.js，无需安装网站运行依赖：

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。

## 使用

- 拖动全屏地球改变视角，点击发光坐标查看对应旅行的漫画、文字、行程与攻略。
- 点击已有记录的国家会打开旅程；同一国家多段旅行会先显示选择列表。
- 点击未记录地区可选点记录新旅程；也可在「写手记」中手动填写经纬度。
- 底部时间轴按旅行日期排列，可直接打开任意一站。
- 「写手记」进入本地管理，可新增、编辑、删除手记和导入导出。
- 选择「生活」可记录没有地理坐标的日常，不会在旅行地图上生成标记。
- 地图标记、地点列表及手记卡片都可以打开完整阅读页。
- 照片在本地压缩后存储，不会自动上传。

## 数据在哪里

当前版本是静态网站。发布内容从 `data.js` 读取；你的编辑只存储在当前浏览器的 localStorage，网址相同的其他浏览器不会自动同步。浏览器容量有限，建议经常导出 JSON 备份。隐身模式及清理网站数据可能丢失本地草稿。

公开网站上的访客即使使用编辑功能，也只会改变自己浏览器的数据，不能修改你的网站文件。这不是带账号登录的在线后台。

发布新内容：在「手记管理」点击「导出发布文件」，将下载的 `data.js` 替换到网站目录，再重新发布。发布后的内容是公开的，导出的 JSON 包含全部手记和封面照片，请自行保管备份。

已有本地草稿的浏览器会优先显示自己的草稿。若要检查最新发布内容，请使用其他浏览器或无草稿的浏览器环境。

## 漫画与文字如何配合

每段旅程先用漫画留住一个具体瞬间，再用一两句短注补充画外音。更完整的感受放在文字手记；行程与实用攻略放到阅读页后半段。预留的三格漫画是开场、途中、回望的结构提示，可以按自己的故事自由调整，不是对实际经历的描述。

每篇手记最多上传 6 张漫画，按上传顺序展示，每张可以配短注。漫画与封面同样只保存在当前浏览器；配图较多时更需要及时备份。

## 地球交互与资源

首页使用本地托管的 D3 7.9.0 绘制正射投影地球（ISC 许可见 assets/D3-LICENSE.txt），所有运行资源随网站一起发布。支持鼠标/触摸拖动、滚轮缩放、缩放按钮、自动旋转开关、方向键旋转和加减号缩放。系统开启减少动态效果时，默认关闭自动旋转。

正文使用从右侧展开的阅读面板；手机上为全屏阅读。首页没有长文章列表，底部只保留按日期排列的旅行时间轴。

## 城市与旅行区间

地图和时间轴按 21 个独立城市／岛屿展示，同一国家的城市各有阅读入口，不绘制城市之间的连线。原先的十段旅行通过 tripId 保留分组。

城市有明确日期时使用 start/end；只有共同旅行区间时，城市日期留空，通过 tripStart/tripEnd 显示「旅行区间」，并说明具体停留日期待补，不将共同区间当作每座城市的完整停留时间。
